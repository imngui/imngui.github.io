ICAT-EGVE 2026

ERUPT: Extended Reality Universal Planning Toolkit

  • Unity
  • ROS 2
  • MoveIt
  • Meta Quest 3

An open-source XR toolkit for interactive motion planning. Users create, scale, and move obstacles with their hands. Edits sync to the MoveIt planning scene in about 40 ms, and planned trajectories can be previewed in VR/AR before running on a physical UR5e. A pre-registered user study comparing ERUPT with the 2D MoveIt/RViz interface is underway.

WAFR 2026

CIPHER: Scalable Multi-Robot Motion Planning

  • C++
  • OMPL
  • MAPF
  • Kinodynamic planning

A hierarchical multi-robot planner that coordinates robots through a workspace decomposition and refines it wherever conflicts arise, so it rarely has to plan in the expensive joint space of all robots. It solved 100% of benchmark problems with up to 32 robots and was up to an order of magnitude faster than state-of-the-art baselines.

CoRL 2026 Workshop

FERRET: Environment Edits as a Corrective Signal

  • PyTorch
  • Graph neural networks
  • Reward learning

When a person drags a robot arm away from a laptop, the robot can't tell which of many changes they meant. FERRET lets people edit the scene instead while the robot's motion stays fixed. It learns preferences from both scene and robot edits using relational and graph neural network models, and recovers features that robot corrections alone cannot.

RADER: Robot Action Demonstration in XR

  • Unity
  • ROS 2
  • Learning from demonstration

An XR interface for teaching robots by demonstration with a virtual arm. Users can safely show the high-cost states that are dangerous to demonstrate on real hardware. Features learned from XR demonstrations matched those learned from demonstrations on a physical UR5e.
